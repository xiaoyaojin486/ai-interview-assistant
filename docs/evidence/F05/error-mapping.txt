Covered by ChatStreamErrorMapperTest:
- 401/403 -> DEEPSEEK_AUTH
- 429 -> DEEPSEEK_RATE_LIMIT
- 5xx -> DEEPSEEK_UNAVAILABLE
- TimeoutException/SocketTimeoutException -> DEEPSEEK_TIMEOUT
- Connection/DNS failure -> DEEPSEEK_UNAVAILABLE
- Unknown failure -> DEEPSEEK_ERROR

The user-facing messages do not contain the original exception message,
upstream response body, full prompt or API key.
